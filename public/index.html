OWN THE RUNTIME

Why self-host?

01

Zero dependencies

Bun runs the TypeScript server and static console directly. No package installation or application build.

02

Single process

HTTP, SSE, ingestion, SQLite, and agent orchestration share one Bun process.

03

Citations by default

Knowledge answers use source labels you can open in the console’s excerpt inspector.

04

Resumable streams

Every thread event is journaled with a sequence number for replay after a disconnect.

05

Guardrails on input and output

Conversation turns pass PII and safety checks before the final reply is delivered.

06

Provider key rotation

A round-robin key pool rotates on rate limits and transient failures, with cooldowns.

BEFORE YOU RUN IT

A few practical answers.

What do I need to run it?

Bun 1.2 or later, writable local storage, and a provider API key. Set SABBIA_MOCK=1 in .env to try deterministic offline inference without a key. Docker Compose is also supported.

Which models does it call?

The explicit registry includes GPT-OSS for text, Nemotron and Llama models for vision and safety, and separate fast routing roles. Live calls use your configured NVIDIA-compatible endpoint. See the full registry and token budgets.

Where does my data go?

SQLite stores conversations, transcript segments, events, and document chunks in your data directory. Original uploads live in its object store. Prompts, relevant source passages, and images used for live inference go to your configured provider. There is no telemetry.

Can I use my own STT and TTS?

Yes. Your telephony or audio application transcribes caller audio, sends the transcript to the Voice API, and turns the returned reply into audio. The Sabbia console accepts text; it does not capture browser audio.

Does it need a vector database?

No. Retrieval combines SQLite FTS5 BM25 results with a lexical fallback using reciprocal rank fusion. It does not require embeddings or a separate vector service.

What licence is it under?

Sabbia AI is licensed under Apache-2.0. You can run it on your own infrastructure and adapt it under that licence.
